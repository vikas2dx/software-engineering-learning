# Project 1: REST Service

## Goal
Create a small Spring Boot API for one resource, such as tasks or bookmarks.

## Work
- Define endpoints, request/response DTOs, and status codes before coding.
- Implement create, read, update, and delete operations with in-memory storage.
- Validate input and return consistent errors for invalid and missing resources.
- Add unit and controller tests and a concise API description.

## Exit criteria
The service starts locally, tests cover the contract and edge cases, and a reviewer can exercise it without reading implementation code.
