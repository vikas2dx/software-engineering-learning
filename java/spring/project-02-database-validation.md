# Project 2: Database and Validation

## Goal
Replace temporary storage with a relational database and make data rules durable.

## Work
- Design tables, keys, constraints, and indexes for current queries.
- Add migrations and repository-based persistence.
- Introduce pagination and stable ordering for collection endpoints.
- Add integration tests against a disposable test database.
- Test transaction boundaries and duplicate/conflicting writes.

## Exit criteria
A clean database can be migrated and seeded, and existing API behavior remains covered by tests.
