# Project 5: CI/CD and Deployment

## Goal
Build and deploy the service repeatably without exposing credentials or losing data.

## Work
- Create a container image and configure externalized runtime settings.
- Automate formatting, tests, and build checks in CI.
- Deploy to a non-production environment with TLS and managed secrets.
- Add database backup and migration/rollback notes.
- Document health checks, release version, and rollback procedure.

## Exit criteria
A clean commit produces a tested artifact that can be deployed and rolled back using documented steps.
