# Java Spring Projects

Build each project with Java and Spring Boot. Each project adds a production concern to one evolving API using Spring MVC, Spring Data JPA, and Spring Security as the relevant stages introduce them. Keep scope small, write acceptance criteria first, and finish with a working demonstration and short decision log.

1. [Project 1: REST service](project-01-rest-service.md)
2. [Project 2: Database and validation](project-02-database-validation.md)
3. [Project 3: Authentication and authorization](project-03-authentication.md)
4. [Project 4: Reliability and observability](project-04-reliability-observability.md)
5. [Project 5: CI/CD and deployment](project-05-deployment.md)

Advance when the exit criteria are met; these projects are milestones, not fixed-duration promises.
