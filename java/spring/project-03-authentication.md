# Project 3: Authentication and Authorization

## Goal
Protect user data and enforce access rules on every relevant endpoint.

## Work
- Add a user identity and secure credential or token flow.
- Hash passwords with a standard password-hashing algorithm; never store plaintext.
- Enforce resource ownership and role-based rules server-side.
- Add positive and negative authorization tests.
- Keep secrets in environment or secret-management configuration.

## Exit criteria
Unauthenticated and cross-user access are denied, credentials are not logged, and the auth flow is documented.
