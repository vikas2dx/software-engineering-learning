# Java Spring Backend Roadmap

This roadmap uses Java with Spring Boot as its backend stack. Core builds the language and server fundamentals, then the Spring track applies them to one evolving service.

The main framework path is Spring MVC for HTTP APIs, Spring Data JPA for relational persistence, Spring Security for authentication and authorization, and Spring Boot Actuator for operational health and metrics.

## Tracks

- [Core](core/README.md): Java, HTTP, SQL, Spring Boot, persistence, testing, and security.
- [Spring](spring/README.md): a sequence of Spring Boot backend projects from a small REST API to a deployed service.

**Completion project:** Deliver a tested, secured, observable Java API backed by a relational database and deployed through a repeatable build process.
