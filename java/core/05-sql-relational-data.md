# SQL and Relational Data

## Learn
- Tables, keys, constraints, joins, aggregation, and normalization basics.
- Indexes and query plans; index for measured query patterns.
- Transactions and ACID properties, isolation, and locking basics.
- Schema migrations and preserving existing data.

## Practice
Design a relational schema for users and orders, write common queries, and inspect the plan for a paginated query.

## Ready when
You can explain the schema from its queries and use constraints to protect data invariants.
