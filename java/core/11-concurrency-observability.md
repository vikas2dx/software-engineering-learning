# Concurrency and Observability

## Learn
- Threads, executors, futures, synchronization, and safe shared state.
- Request timeouts, bounded pools, and backpressure under load.
- Structured logging, metrics, tracing, and health/readiness checks.
- JVM memory basics, garbage collection signals, and profiling tools.

## Practice
Add request correlation and metrics to a service. Load-test a slow dependency and observe thread, latency, and error behavior.

## Ready when
You can identify a bottleneck from measurements and know how the service behaves when a dependency is slow.
