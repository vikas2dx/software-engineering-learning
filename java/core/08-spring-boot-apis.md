# Spring Boot APIs

## Learn
- Application configuration, controllers, DTOs, and validation.
- Central exception handling and consistent error payloads.
- Configuration properties and environment-specific settings.
- OpenAPI documentation and compatibility of public contracts.

## Practice
Build a CRUD API with request validation, pagination, and documented error responses. Keep controllers focused on HTTP translation.

## Ready when
The API contract is documented and invalid requests produce predictable, useful responses.
