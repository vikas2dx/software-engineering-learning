# Collections and Generics

## Learn
- `List`, `Set`, `Map`, queues, iteration, and collection mutability.
- Equality and `hashCode` contracts for keys and set members.
- Generic types, bounded type parameters, and wildcards (`? extends` / `? super`).
- Stream pipelines, laziness, side effects, and when a loop is clearer.

## Practice
Aggregate order records by customer and status. Choose collections from access patterns and test ordering and duplicate behavior.

## Ready when
You can choose a collection based on behavior and use generics without raw types or unsafe casts.
