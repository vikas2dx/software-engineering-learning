# HTTP and REST

## Learn
- Request methods, status codes, headers, content types, and caching semantics.
- Resource-oriented endpoint design, pagination, filtering, and versioning.
- Idempotency, retries, timeouts, and safe error response design.
- Authentication versus authorization and TLS basics.

## Practice
Design an API contract for a resource before implementing it. Include validation errors, missing resources, conflicts, and pagination.

## Ready when
Clients can predict API behavior from the contract and repeated requests have deliberate semantics.
