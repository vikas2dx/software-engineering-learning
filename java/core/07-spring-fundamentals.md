# Spring Fundamentals

## Learn
- Inversion of control, dependency injection, beans, and configuration.
- Constructor injection, bean scopes, and application context startup.
- Profiles and externalized configuration.
- Spring MVC request handling and validation boundaries.

## Practice
Create a small Spring context with constructor-injected services. Replace one dependency in a focused test.

## Ready when
You can explain how a bean is created and avoid hidden field injection or unnecessary framework coupling.
