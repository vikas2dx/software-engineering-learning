# Backend Security

## Learn
- Authentication, authorization, roles, and resource ownership checks.
- Password hashing, token/session lifecycle, and secure cookie or bearer-token handling.
- Input validation, SQL injection prevention, CSRF and CORS where applicable.
- Secret storage, TLS, dependency updates, and privacy-conscious logging.

## Practice
Protect API routes and write tests for both authorized and forbidden access, including access to another user's resource.

## Ready when
Security checks are enforced server-side and negative access cases are covered by tests.
