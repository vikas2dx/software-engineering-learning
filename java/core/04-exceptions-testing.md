# Exceptions and Testing

## Learn
- Checked and unchecked exceptions and where each communicates useful recovery behavior.
- Preserve causes and translate low-level failures at application boundaries.
- JUnit tests, assertions, parameterized cases, and test naming around behavior.
- Mockito or fakes for boundaries; avoid mocking simple value objects.

## Practice
Test a service's validation and failure cases. Verify both successful outcomes and expected exception-to-HTTP mappings.

## Ready when
Failures are actionable and tests cover behavior without depending on private implementation details.
