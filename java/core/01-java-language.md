# Java Language Foundations

## Learn
- Primitive and reference types, variables, operators, and control flow.
- Methods, packages, access modifiers, and standard input/output.
- `String`, immutability, records, enums, and `Optional` use cases.
- Compile/run workflow, Javadoc, and reading compiler diagnostics.

## Practice
Build a command-line expense summary with input parsing and validation. Test empty input, malformed values, and numeric boundaries.

## Ready when
You can write small programs with explicit types and explain how values move through method calls.
