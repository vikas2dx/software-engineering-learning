# Material and Accessibility

## Learn
- Material components, color schemes, typography, shapes, and themes.
- Semantics, labels, touch target size, focus order, and screen-reader behavior.
- Contrast, dynamic type, and non-color status indicators.
- Platform conventions and accessibility testing tools.

## Practice
Build a form and test it with TalkBack, keyboard navigation, and increased font size. Add semantics only where defaults are insufficient.

## Ready when
Core actions are discoverable and usable without relying on color, precise gestures, or small text.
