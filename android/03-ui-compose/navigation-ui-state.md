# Navigation and UI State

## Learn
- Navigation destinations, arguments, back stack, and deep links.
- Screen state versus navigation state and process restoration.
- ViewModel ownership and lifecycle-aware state collection.
- One-off effects such as navigation and messages without replay bugs.

## Practice
Build a multi-screen flow with arguments, back navigation, and restored state after recreation.

## Ready when
Navigation is driven by explicit user events and screen state survives the lifecycle events it is expected to survive.
