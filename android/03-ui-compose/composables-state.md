# Composables and State

## Learn
- Composable functions, recomposition, stability, and unidirectional data flow.
- State hoisting, immutable UI state, and event callbacks.
- `remember`, `rememberSaveable`, and state ownership boundaries.
- Side-effect APIs and why effects must be keyed to their inputs.

## Practice
Build a form with hoisted state, validation events, and state restoration. Keep composables free of direct network or database calls.

## Ready when
UI output follows explicit state and user actions flow back through callbacks to the state owner.
