# Compose Layout and Lazy Lists

## Learn
- Rows, columns, boxes, modifiers, constraints, and measurement.
- `LazyColumn` and `LazyRow`, stable keys, and content types.
- Adaptive layouts and window size classes.
- Scrolling state, item animations, and avoiding nested scrolling pitfalls.

## Practice
Create an adaptive list-detail screen with a large data set, stable item keys, and empty/loading/error states.

## Ready when
The layout works across window sizes and large lists remain efficient and correctly keyed.
