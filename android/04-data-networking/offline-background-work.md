# Offline and Background Work

## Learn
- Local-first display, cache freshness, and synchronization state.
- WorkManager constraints, retries, unique work, and idempotent jobs.
- Connectivity as an unreliable signal rather than a guarantee of reachability.
- Conflict handling and clear pending, stale, and failed UI states.

## Practice
Queue a user action while offline and synchronize it with unique background work. Test retries and duplicate execution.

## Ready when
The feature remains understandable offline and background tasks are safe to retry.
