# REST Networking

## Learn
- HTTP methods, status codes, headers, JSON serialization, and timeouts.
- Retrofit or another client, interceptors, and typed API boundaries.
- Mapping transport errors to domain outcomes and safe retry rules.
- Authentication renewal and avoiding sensitive data in logs.

## Practice
Build a repository over a REST API. Test success, timeout, unauthorized response, malformed payload, and server errors with a fake client.

## Ready when
The UI does not depend on HTTP details and every expected network failure becomes a deliberate app state.
