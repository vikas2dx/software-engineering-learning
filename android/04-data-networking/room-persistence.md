# Room Persistence

## Learn
- Entities, data access objects, queries, and database ownership.
- Relations, indexes, transactions, and observable query results.
- Schema export, migrations, and migration testing.
- Local source of truth patterns when combining local and remote data.

## Practice
Persist a searchable collection and add a migration from a prior schema. Verify the UI observes database updates.

## Ready when
Schema changes preserve user data and queries are designed around actual access patterns.
