# Kotlin Language Basics

## Learn
- `val` and `var`, primitive-like types, strings, ranges, and control flow.
- Nullable types, safe calls, Elvis operator, and smart casts.
- Functions, named/default arguments, lambdas, and higher-order functions.
- Data classes, sealed hierarchies, and exhaustive `when` expressions.

## Practice
Write a small command-line task tracker with parsing, validation, and unit tests. Model invalid input and missing values without unchecked assertions.

## Ready when
You can explain the types and nullability of a function's inputs and outputs and use sealed types to represent finite states.
