# Collections and Generics

## Learn
- Read-only and mutable collection interfaces and their concrete implementations.
- Transformations such as `map`, `filter`, `associate`, and `groupBy`.
- Generic types, variance (`in` and `out`), and type constraints.
- Equality, hash codes, and stable identifiers for collection items.

## Practice
Transform a list of API records into grouped UI sections. Add tests for empty input, duplicate identifiers, and ordering.

## Ready when
You can select an appropriate collection, preserve meaningful ordering, and use generics without weakening type safety.
