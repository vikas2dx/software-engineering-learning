# Object-Oriented Kotlin

## Learn
- Classes, primary and secondary constructors, properties, and visibility.
- Interfaces, inheritance, abstract classes, and delegation.
- Extension functions, object declarations, and companion objects.
- Composition over inheritance and small interfaces at useful boundaries.

## Practice
Model a small checkout flow with interchangeable payment strategies. Keep business rules independent from Android classes and test them directly.

## Ready when
You can create focused types with clear ownership and avoid class hierarchies that exist only to share a few lines of code.
