# Android Roadmap

This roadmap focuses on native Android development with Kotlin and Jetpack Compose. Follow the stages in order, but build small features throughout instead of waiting until the end.

## Stages

1. [Kotlin foundations](01-kotlin-foundations/README.md)
2. [Android fundamentals](02-android-fundamentals/README.md)
3. [UI with Jetpack Compose](03-ui-compose/README.md)
4. [Data and networking](04-data-networking/README.md)
5. [Architecture](05-architecture/README.md)
6. [Testing](06-testing/README.md)
7. [Platform quality](07-platform-quality/README.md)
8. [Build and release](08-build-release/README.md)

**Checkpoint project:** Ship a Compose app with navigation, a remote API, Room persistence, offline-tolerant states, automated tests, and a repeatable signed release process.
