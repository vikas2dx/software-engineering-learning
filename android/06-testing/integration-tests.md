# Integration Tests

## Learn
- Instrumented tests, test devices, and managing app state between runs.
- Testing navigation, persistence, and network boundaries together.
- Fakes and test servers for deterministic scenarios.
- Selecting a small set of high-value end-to-end journeys.

## Practice
Automate sign-in or a key data-entry flow from launch through persisted result. Include one failure path.

## Ready when
The critical journey is repeatable in CI and failures identify the broken user-visible behavior.
