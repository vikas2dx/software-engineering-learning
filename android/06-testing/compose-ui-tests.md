# Compose UI Tests

## Learn
- Compose semantics tree and finding nodes by role, text, or content description.
- Testing user actions and visible outcomes rather than implementation details.
- Controlling state and synchronization in UI tests.
- Accessibility checks and screenshot testing tradeoffs.

## Practice
Test a form's validation and submission states. Ensure selectors use semantics that a user or assistive technology can perceive.

## Ready when
Tests cover core interactions without relying on fragile layout coordinates or sleeps.
