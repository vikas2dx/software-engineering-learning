# Unit and Coroutine Tests

## Learn
- JUnit, assertions, test fixtures, and deterministic dependencies.
- Fake repositories versus mocks and testing observable state.
- Coroutine test dispatchers, virtual time, and cancellation.
- Testing edge cases without depending on Android framework objects.

## Practice
Test ViewModel state transitions for success, empty results, and failure using a fake repository and a test scheduler.

## Ready when
Tests are deterministic, focused on outcomes, and fast enough to run continuously.
