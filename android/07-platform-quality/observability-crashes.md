# Observability and Crash Handling

## Learn
- Crash reports, non-fatal errors, structured logs, and privacy-safe metadata.
- App startup, network failure, and ANR indicators.
- Release/version correlation and symbol or mapping file upload.
- Alerts, triage, and regression verification.

## Practice
Configure a non-production reporting environment and verify a test crash is searchable by app version without exposing user secrets.

## Ready when
An issue can be tied to a release and investigated with useful, privacy-conscious context.
