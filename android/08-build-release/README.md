# Build and Release

## Learn
- Build variants, product flavors, version codes, and environment configuration.
- Signing keys, Play App Signing, and secret management.
- Continuous integration for formatting, analysis, tests, and artifact builds.
- Internal testing, staged rollout, release notes, monitoring, and rollback.

## Practice
Automate a debug build and test suite, then document the signed release workflow without committing credentials.

## Ready when
A teammate can reproduce the release and identify the exact artifact and configuration that shipped.
