# Project Structure and Gradle

## Learn
- Android project structure, modules, source sets, and the manifest.
- Gradle plugins, dependencies, build variants, and version catalogs.
- Debug versus release configuration and generated build outputs.
- Keep credentials out of source control and understand dependency updates.

## Practice
Create a small app with debug and release variants. Add one library, inspect the dependency graph, and build from the command line.

## Ready when
You can explain where app code, resources, manifest entries, and build configuration belong.
