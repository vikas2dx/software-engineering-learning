# Resources and Configuration

## Learn
- Resource qualifiers, strings, dimensions, images, and localization.
- Density-independent units and screen configuration changes.
- Runtime permissions and capability checks as part of feature flow.
- Configuration-aware APIs and avoiding hard-coded device assumptions.

## Practice
Localize a small screen, add an alternate layout or resource where useful, and verify large font settings and a narrow screen.

## Ready when
Content adapts to locale and device configuration without requiring device-specific branches throughout the UI.
