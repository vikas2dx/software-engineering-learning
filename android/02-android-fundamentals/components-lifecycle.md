# Components and Lifecycle

## Learn
- Activities and their lifecycle callbacks and saved state.
- Intents, tasks, back stack behavior, and activity results.
- Services, broadcast receivers, and content providers at a conceptual level.
- Configuration changes, process recreation, and lifecycle-aware APIs.

## Practice
Test a screen through rotation, background/foreground transitions, and process recreation. Persist user-visible state at the appropriate layer.

## Ready when
You distinguish configuration changes from process death and do not rely on an Activity instance as durable state storage.
