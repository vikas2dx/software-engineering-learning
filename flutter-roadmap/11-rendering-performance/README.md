# Rendering and Performance

Measure before optimizing. Use profile mode and representative devices or workloads.

## Learn
- Frame budgets, UI and raster work, jank, startup, memory, and battery costs.
- DevTools performance, memory, and network views.
- Lazy collections, image sizing and caching, and avoiding expensive build work.
- Profile mode versus debug mode and repeatable performance measurements.
- Accessibility and smooth behavior on lower-end hardware.

## Practice
Profile a scrolling screen with realistic data, identify the largest measured cost, make one change, and compare the same workload.

## Ready when
You can point to a measurement that improved and explain any tradeoff introduced by the optimization.
