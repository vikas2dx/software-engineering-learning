# Dart Fundamentals

## Learn
- Variables and finality: `var`, `final`, and `const`.
- Built-in types, records, enums, collections, and collection literals.
- Control flow, pattern matching, exceptions, imports, and libraries.
- Iterables and common transformations such as `map`, `where`, and `fold`.

## Practice
Write a command-line program that parses a list of tasks, filters them by status, and reports summary counts. Add tests for empty input and malformed values.

## Ready when
You can choose appropriate types and collection operations, explain when a value is mutable, and test ordinary and edge-case behavior.
