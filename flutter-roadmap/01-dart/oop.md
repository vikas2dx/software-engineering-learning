# Object-Oriented Programming

## Learn
- Classes, constructors, factory constructors, and named constructors.
- Encapsulation, interfaces, inheritance, mixins, and composition.
- Abstract classes, generics, extension methods, and operator methods.
- When simple data types or functions are clearer than a class hierarchy.

## Practice
Model a small library domain with books, loans, and due dates. Keep rules in testable domain objects and prefer composition where types vary by behavior.

## Ready when
You can choose a small, understandable abstraction and explain its responsibilities and extension points.
