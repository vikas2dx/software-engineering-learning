# Functions

## Learn
- Positional, named, optional, and default parameters.
- Function types, closures, callbacks, and tear-offs.
- Lexical scope and how closures capture values.
- Pure functions, small focused functions, and meaningful return types.

## Practice
Extract validation and calculation logic from a small program into functions. Pass behavior through a callback and test the functions without UI or global state.

## Ready when
You can describe a function's inputs and outputs clearly and avoid hidden side effects in reusable logic.
