# CI/CD and Release

Make builds reproducible, secrets controlled, and releases recoverable.

## Learn
- Formatting, static analysis, tests, and build checks in continuous integration.
- Build flavors, environment configuration, signing, and version numbers.
- Secure handling of signing keys and CI secrets.
- Store submission, staged rollout, crash monitoring, and rollback planning.
- Reproducible artifacts and release notes.

## Practice
Automate analysis, tests, and a non-production build. Document the signed release path without committing credentials.

## Ready when
A teammate can reproduce the release process and identify the artifact, configuration, and version that shipped.
