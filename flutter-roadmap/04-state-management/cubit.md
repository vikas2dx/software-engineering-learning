# Cubit

## Learn
- State transitions through methods rather than event objects.
- Immutable state, equality, and representing asynchronous outcomes.
- Cubit ownership, injection, and close behavior.
- How Cubit differs from BLoC in ceremony and event visibility.

## Practice
Build a form Cubit with validation and submission states. Test each public action and its emitted states.

## Ready when
You can decide whether direct methods or explicit events make the feature easier to understand and debug.
