# Provider

## Learn
- Providing and consuming dependencies through the widget tree.
- `ChangeNotifier` lifecycle, notifications, and listener cleanup.
- Separating dependency lookup from state mutation.
- Testing notifiers independently and widgets with injected dependencies.

## Practice
Build a small cart state object and expose it to multiple screens. Confirm updates are narrowly scoped and listeners are disposed.

## Ready when
You can explain the lifetime of a provided object and avoid using a notifier as an unstructured global store.
