# BLoC

## Learn
- Event-to-state flow and explicit event handlers.
- State immutability, event ordering, and asynchronous handler behavior.
- Repository boundaries, transformations, and error mapping.
- Bloc testing with controlled events and expected state sequences.

## Practice
Implement a search feature that debounces input, reports loading and results, and handles failures. Test the emitted sequence.

## Ready when
You can trace an event to its resulting states and explain why the explicit flow helps your team.
