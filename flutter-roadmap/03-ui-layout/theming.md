# Theming

## Learn
- `ThemeData`, `ColorScheme`, text themes, component themes, and theme extensions.
- Light and dark appearance, system preference, and runtime theme selection.
- Semantic color and typography roles rather than scattered literal values.
- Contrast, focus states, and text scaling.

## Practice
Define a small design system and apply it to buttons, forms, navigation, and error states. Verify both color schemes and high text scaling.

## Ready when
A visual change can be made centrally and the interface remains legible in all supported themes.
