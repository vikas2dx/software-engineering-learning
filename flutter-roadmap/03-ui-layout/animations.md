# Animations

## Learn
- Implicit animations for straightforward value transitions.
- `AnimationController`, `TickerProvider`, tweens, curves, and disposal.
- Hero transitions and route transitions where they improve continuity.
- Reduced-motion preferences, interruption, and frame-budget awareness.

## Practice
Animate a state change and a route transition. Verify controllers are disposed and interactions remain responsive during animation.

## Ready when
You can choose the simplest animation API that fits and avoid animation that obscures state or blocks input.
