# Responsive UI

## Learn
- Layout constraints flow down and sizes flow up; avoid assumptions about device models.
- Use `LayoutBuilder` and breakpoints based on available space.
- Account for text scaling, safe areas, keyboard insets, and orientation.
- Use adaptive navigation and input patterns where platform conventions differ.

## Practice
Build the same feature for narrow and wide windows. Test with large text, landscape orientation, and a visible keyboard.

## Ready when
The layout remains usable across window sizes and accessibility settings without clipping or overflow.
