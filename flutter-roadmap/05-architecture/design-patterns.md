# Design Patterns

## Learn
- Recognize composition, strategy, adapter, factory, and observer patterns.
- Understand how Flutter's widget composition and callbacks support these ideas.
- Prefer language and framework conventions over recreating a pattern by name.
- Evaluate patterns by the coupling and change they remove.

## Practice
Use an adapter around one external API and a strategy for two interchangeable policies. Compare the result with a simpler direct implementation.

## Ready when
You can describe the tradeoff a pattern introduces and remove it when it adds indirection without value.
