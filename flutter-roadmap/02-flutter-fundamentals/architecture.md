# Flutter Architecture

## Learn
- The framework, engine, and embedder responsibilities.
- How Dart code produces a widget description that flows through the element and render-object trees.
- The role of the event loop, scheduler, and platform embedding.
- Where application logic belongs versus framework and platform responsibilities.

## Practice
Trace a tap from a callback through a state update to a rendered frame. Use Flutter DevTools to inspect the widget tree and frame timeline.

## Ready when
You can explain the broad path from app code to pixels and know which layer to inspect when behavior is wrong.
