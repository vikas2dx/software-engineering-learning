# Widget System

## Learn
- Widgets are immutable descriptions; elements retain identity across updates.
- Render objects perform layout, painting, and hit testing.
- Composition, keys, constraints, and parent-child layout contracts.
- How `BuildContext` relates to an element and inherited information.

## Practice
Build a reusable form field and a custom layout from smaller widgets. Inspect the widget, element, and render-object trees in DevTools.

## Ready when
You can choose composition boundaries, explain what a key identifies, and diagnose a layout from its constraints.
