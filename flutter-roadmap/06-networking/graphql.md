# GraphQL

## Learn
- Schemas, queries, mutations, fragments, variables, and typed operations.
- Partial data and errors in one response.
- Pagination patterns and client-side caching tradeoffs.
- When GraphQL helps clients and when a simpler REST API is sufficient.

## Practice
Build a typed query and mutation for one feature. Handle partial errors and paginate a collection without duplicating records.

## Ready when
You can explain the contract between schema and client and make caching and pagination behavior explicit.
