# Observability and SLOs

## Learn
- Logs, metrics, traces, and the questions each can answer.
- Service-level indicators, objectives, and error budgets.
- Alert on user-impacting symptoms and keep alerts actionable.
- Correlation IDs, cardinality limits, and privacy-safe telemetry.

## Practice
Define availability and latency indicators for an API. Trace a request across services and specify one alert tied to user impact.

## Ready when
Operators can detect and investigate user-visible problems without relying on unstructured guesswork.
