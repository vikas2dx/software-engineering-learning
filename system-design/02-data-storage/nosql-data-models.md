# NoSQL Data Models

## Learn
- Key-value, document, wide-column, and graph access patterns.
- Partition keys, distribution, hot partitions, and data locality.
- Denormalization and the consistency work it shifts to application code.
- Managed service limits, query constraints, and cost models.

## Practice
Take known query patterns and model them in a document or key-value store. Identify duplicated data and how it is updated safely.

## Ready when
The chosen model directly supports required queries and you can state the consistency and operational tradeoffs.
