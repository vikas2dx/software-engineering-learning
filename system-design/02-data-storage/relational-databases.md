# Relational Databases

## Learn
- Tables, keys, constraints, joins, normalization, and schema evolution.
- Transactions, isolation levels, locking, and consistency boundaries.
- Indexes and query plans based on real access patterns.
- Replication and read replicas, including replication lag.

## Practice
Model orders and inventory with constraints. Trace how a multi-step purchase preserves invariants during concurrent requests.

## Ready when
You can explain which invariants the database enforces and where transaction boundaries begin and end.
