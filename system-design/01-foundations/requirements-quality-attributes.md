# Requirements and Quality Attributes

## Learn
- Separate functional requirements from quality attributes and constraints.
- Clarify actors, use cases, data ownership, and system boundaries.
- Make latency, availability, durability, consistency, and privacy measurable.
- Prioritize goals when they conflict instead of claiming every property is maximal.

## Practice
For a file-sharing service, write the core user journeys and measurable goals. List assumptions and questions that would change the architecture.

## Ready when
You can explain what the system must do, what quality it must provide, and what is explicitly out of scope.
