# Network and API Fundamentals

## Learn
- DNS, TCP, TLS, HTTP, proxies, and common sources of network latency.
- REST and RPC tradeoffs, API contracts, versioning, and pagination.
- Timeouts, retries, idempotency, and request correlation.
- Synchronous calls versus asynchronous messaging.

## Practice
Trace one request from client through gateway and service to storage. Mark network boundaries, timeouts, and error responses.

## Ready when
You can identify each network hop and explain what the caller observes when that hop fails.
